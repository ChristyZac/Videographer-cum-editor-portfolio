# FRAME — Videographer & Video Editor Portfolio

A responsive portfolio starter built with **React + TypeScript + Vite**.

## Included
- Three requested main sections: **About Me**, **Tools & Technologies**, and **My Works**
- Dark cinematic design with lime accents
- Responsive desktop/mobile navigation
- Sample work grid with clickable project-detail modals
- Contact section with email link
- Sample tools: Adobe Premiere Pro, CapCut, DaVinci Resolve, Adobe After Effects

## Run locally
1. Install Node.js (LTS): https://nodejs.org/
2. Extract this ZIP and open the project folder in a terminal.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open the local URL shown by Vite (usually `http://localhost:5173`).

## Build for production
```bash
npm run build
npm run preview
```

## Personalise before publishing
- In `src/App.tsx`, replace `[Your Name]` and `[YOUR NAME]`.
- Replace `hello@example.com` with your contact email.
- Replace the sample project names, categories, descriptions, and Unsplash image URLs in the `projects` array with your own work.
- For actual videos, replace project images or add embedded video links in the project modal.
- Update the browser title in `index.html`.

The sample images are loaded from Unsplash, so an internet connection is needed to display them. This is a starter template; project thumbnails are placeholders, not claims about completed client work.
